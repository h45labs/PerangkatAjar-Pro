👋 Tentang Aplikasi

Perangkat Ajar KBC Pro adalah aplikasi web satu file HTML yang membantu guru menyusun seluruh perangkat ajar berbasis Kurikulum Berbasis Cinta (KBC) — pendekatan yang menempatkan kasih sayang sebagai jantung pembelajaran.

Dibuat untuk semua guru di semua jenjang: SD/MI, SMP/MTs, SMA/MA, hingga SMK/MAK — baik sekolah umum maupun madrasah. Berjalan tanpa internet, tanpa install, tanpa biaya. Cukup buka di browser HP atau laptop. 📱💻

📤 Berbagi ke sesama guru: bagikan tautan aplikasi, kirim file HTML via WhatsApp, atau gunakan Export/Import JSON di menu Data.

✨ Fitur Lengkap (16 Menu)

📘 Modul AjarGenerator otomatis dengan afirmasi, cek perasaan, refleksi syukur, remedial kasih sayang.
📑 KTP & ATPKumpulan & Alur Tujuan Pembelajaran — generate otomatis dari daftar TP.
🎯 KKTPKriteria Ketercapaian TP 4 level: Baru Berkembang → Mahir.
📅 Prota & PromesProgram Tahunan & Semester otomatis dari TP, baris dapat diedit.
📝 Bank SoalPG / Isian / Uraian → kisi-kisi, lembar soal, kunci jawaban siap cetak.
🧠 Kuis SiswaKuis interaktif — jawaban salah disambut pesan penyemangat, bukan hukuman.
📋 LKPD BuilderLembar Kerja Peserta Didik dengan bahasa positif otomatis.
📊 Analisis NilaiStatus "Perlu Pendampingan 🌱" — bukan "gagal".
💬 Afirmasi & ApresiasiAfirmasi harian, Kartu Apresiasi, "2 Bintang 1 Harapan".
🌱 Refleksi & PerasaanRefleksi siswa, refleksi guru, cek perasaan harian (siap cetak).
📓 Jurnal MengajarJurnal harian dengan kolom "siswa yang perlu perhatian 💚".
💾 DataSimpan otomatis di browser + Export/Import JSON antar perangkat.

🚀 Cara Menggunakan

A. Langsung Online (Rekomendasi)

  1. Buka https://h45labs.github.io/kbc/ di browser
  2. Aplikasi langsung jalan — bisa dibookmark
  3. Di HP: menu ⋮ → "Tambahkan ke layar utama" agar seperti aplikasi

B. Offline di HP / Laptop

  1. Unduh file index.html dari repo ini (atau terima via WhatsApp)
  2. Buka dengan Chrome / Firefox — klik dua kali di laptop
  3. Selesai — semua fitur berjalan tanpa internet
⚠️ Gunakan Chrome atau Firefox. Hindari Opera Mini/UC Browser (fitur simpan & cetak tidak stabil). Rutin Export JSON sebagai cadangan data.
