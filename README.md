<h2>📖 Tentang</h2>
<p>
Perangkat Ajar PRO adalah aplikasi web satu file (<code>index.html</code>) untuk membantu guru
menyusun perangkat ajar secara cepat: modul ajar, KTP &amp; ATP, KKTP, Prota &amp; Promes,
bank soal, LKPD, analisis nilai, hingga jurnal harian. Semua berjalan di browser,
tanpa server dan tanpa akun.
</p>
</div>

<h2>🚀 Cara Menggunakan</h2>

<h3>Opsi 1 — Langsung online</h3>
<p>Buka link demo di bagian atas, lalu mulai dari menu <b>Identitas</b>.</p>

<h3>Opsi 2 — Jalankan lokal</h3>
<ol>
  <li>Unduh repositori ini (<code>Code → Download ZIP</code>) atau <code>git clone</code>.</li>
  <li>Buka file <code>index.html</code> di browser (Chrome, Edge, Firefox, Safari).</li>
  <li>Selesai. Tidak perlu instalasi apa pun.</li>
</ol>

<h3>Opsi 3 — Deploy sendiri di GitHub Pages</h3>
<ol>
  <li>Fork repositori ini.</li>
  <li>Buka <code>Settings → Pages</code>.</li>
  <li>Pilih <i>Deploy from a branch</i>, branch <code>main</code>, folder <code>/ (root)</code>, lalu Save.</li>
</ol>
</div>

<div>
<h2>💾 Penyimpanan Data &amp; Privasi</h2>
<ul>
  <li>Data disimpan di <code>localStorage</code> browser masing-masing; <b>tidak dikirim ke server mana pun</b>.</li>
  <li>Data tidak berpindah antar perangkat/browser. Gunakan menu <b>💾 Data → Ekspor</b> untuk backup rutin.</li>
  <li>Menghapus data browser (clear cache/site data) akan menghapus data aplikasi.</li>
  <li>⚠️ File backup (<code>perangkat-ajar-pro-backup.json</code>) bisa memuat data guru/siswa. Jangan diunggah ke repositori publik.</li>
</ul>
</div>
